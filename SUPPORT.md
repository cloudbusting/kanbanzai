# Support

Kanbanzai is a local tool with one repository: the command, the Claude Code plugin, the OpenCode plugin and the board
extension.

## Where to look first

- [README](README.md) — install, set up a project, the settings, the command and the
  [compatibility table](README.md#compatibility).
- [board-view/README.md](board-view/README.md) — the editor tab, its install and its settings.
- `kanbanzai --version`, `kanbanzai check` and `kanbanzai config` — the version, the briefs' state and the resolved
  settings. Most setup problems show up in one of them.

## Ask a question or report a bug

Open an issue: <https://github.com/cloudbusting/kanbanzai/issues>

Say which version (`kanbanzai --version`), which harness or editor you use and its version, the OS, and what you
expected. A failing `kanbanzai check` or `kanbanzai config` line is usually enough to start.

## Security

Do not report a vulnerability in a public issue. Follow [SECURITY.md](SECURITY.md) and use a private GitHub Security
Advisory.
